Dental Demo Static
==================

Esta carpeta contiene una versión estática del demo en HTML puro.

Cómo abrirla
------------

1. Abre esta carpeta en tu computadora.
2. Haz doble clic en `index.html`.
3. Navega entre:
   - `index.html`
   - `nosotros.html`
   - `proceso.html`
   - `guia-pacientes.html`
   - `agendar.html`

No necesitas correr terminal, npm, ni servidor local.

Notas
-----

- Esta exportación es visual y navegable.
- El flujo de agenda aquí es estático; la versión original lo hacía con Next.js.
